City Data Reporter
-

Description
-
City Data Reporter is a Python program that is able to use live weather information for any city of the user's choice 
using the OpenWeatherMap API. THe program ask the user for a city name, the city's weather data is retrieved from the 
API, the response gets processed, displays the information to the user, and lasty the results are stored in the 
"city_data.csv" file.

Features
- 

    - User inputs city name
    - Ensures there is an input
    - Live weather information from OpenWeatherMap
    - Displays city, country, temperature, humidity, and a description of the weather to the user
    - API temperature convered to Celsius from Kelvin.
    - Information is stored in the "city_data.csv"
    - Handles error codes

Requirements
-
- Python

- Libraries needed:
    - requests
    - json
    - csv

API Key
-
This project was made with the help of OpenWeatherMap API.

Create a free account online, then you will receive an
API key from their website.

    PSA!!!
    DO not put your API key into any public domain.
    These key is private and should be kept safe.

How to Run:
-

1. Open the "reporter.py"
2. You will be prompted to enter a city, enter a city then press enter
3. After, you can look in the "city_data.csv file" to see the saved information
